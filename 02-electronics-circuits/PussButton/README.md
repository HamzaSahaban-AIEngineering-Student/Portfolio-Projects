# 5V LED Circuit with Push Button

A simple electronic circuit built on Tinkercad featuring a Red LED controlled by a Push Button and powered by a 5V DC Power Supply through a current-limiting resistor.

## 📸 Circuit Overview
* **Power Supply:** 5V DC
* **Control:** Push Button (Tactile Switch)
* **Resistor:** 220 Ω / 330 Ω (Current-limiting)
* **Output:** Red LED
* **Measured Current:** ~13.5 mA (When button is pressed)

## 🛠️ How It Works
1. When the push button is released, the circuit remains open, and the current consumption is `0.00 A`.
2. When the push button is pressed, the circuit closes, allowing current to flow through the resistor and LED, lighting it up safely with a current draw of `~13.5 mA`.
