## Featured project: Smart 4-Way Traffic Light

A 4-way traffic-light controller designed and simulated with digital logic in Logisim.

- Topics: digital logic, sequential logic, state-based control

## How to open the files

1. Install or open Logisim / Logisim-evolution.
2. Download any `.circ` file from this folder.
3. Open the file in Logisim to inspect and simulate the circuit.

These are coursework and practice designs. The files are kept together to document progress across combinational and sequential digital logic.
