SERVICE LEVEL AGREEMENT

These terms govern all commercial software engineering, workflow automation, and self-hosted infrastructure deployments provided by Root Rob Agency.

[ TERMS // 01 ]

1. Scope of Commercial Services

Root Rob provides custom software development, workflow automations (n8n), AI agent deployments, database pipelines (PostgreSQL/NocoDB), and private Docker infrastructure setup. All deliverables are defined in the specific project intake agreement.

[ TERMS // 02 ]

2. Self-Hosted Infrastructure & Maintenance SLAs

When deploying software on dedicated client VPS servers, the client retains full ownership of hosting costs and access credentials. Optional monthly maintenance agreements cover Docker container updates, security patches, and pipeline health monitoring.

[ TERMS // 03 ]

3. Intellectual Property & Code Ownership

Upon full payment of setup fees, clients receive full operational rights to their custom workflows, database configurations, and proprietary scripts. Open-source components remain governed by their respective open-source licenses.

[ TERMS // 04 ]

4. Payment Terms & Setup Schedules

Projects require a mutually agreed initial setup deposit prior to deployment. Recurring server maintenance fees, if selected, are billed monthly. One-time setup fees are non-refundable once infrastructure engineering has commenced.

[ TERMS // 05 ]

5. Limitation of Liability & Data Integrity

Root Rob is not liable for data loss caused by unauthorized client server modifications, unmaintained VPS environments, or third-party API provider downtime (e.g., WhatsApp, Telegram). Clients are advised to maintain scheduled database backups.
